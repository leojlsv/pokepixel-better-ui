# Asset provenance

This record documents the facts established for raster assets shipped inside
the Better UI userscript. It does not claim original authorship where the
repository history does not establish it.

## Redistribution status

**Status: cleared for MIT redistribution.** On 2026-10-05, the Product Owner
explicitly confirmed that they hold sufficient rights to redistribute the source
assets listed below and their Better UI runtime derivatives under this
repository's MIT License.

That confirmation establishes the project's redistribution permission for these
files. It does not add an unsupported claim about who originally authored each
source image.

The six 1254×1254 menu images were recorded in project history as
"Product Owner-provided artwork". Their 96×96 runtime versions are derivatives
created for embedding in the userscript. The Pokémon Profile icon was recorded
as a Product Owner-requested repository asset. Original authorship beyond those
historical facts is not asserted here.
